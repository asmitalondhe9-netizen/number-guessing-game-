# 🎯 Number Guessing Game

A simple console-based Number Guessing Game developed in C++.

## 📌 About
The program generates a random number, and the player keeps guessing until the correct number is found.

## ✨ Features
- Random number generation
- User input
- Guess comparison
- Multiple attempts
- Result display

## 🧠 Concepts Used
- Variables
- Conditional statements
- Loops
- Random number generation
- Basic problem-solving

## ▶️ How to Run
Compile and run number_guessing_game.cpp using any C++ compiler.
